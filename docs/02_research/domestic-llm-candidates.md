## 概要

デジタル庁は2025年12月〜2026年1月に源内で試用する国産LLMを公募。15件の応募から7件を選定し、2026年8月頃から源内上での試用を開始予定。

---

## 選定された5社（契約締結済み）

公式発表では7件選定・5社と契約とある。

| 企業 | モデル名 | 特徴 |
|---|---|---|
| **NTTデータ** | tsuzumi / tsuzumi 2 | NTTが1980年から積み重ねた自然言語処理研究の成果。30Bパラメータで1GPU動作。オンプレ対応 |
| **ソフトバンク** | PLaMo（PLaMo翻訳） | 日英翻訳特化モデル。すでに源内で2025年12月から翻訳機能として稼働中 |
| **NEC** | 未公表 | - |
| **富士通** | Takane（高根） | 量子化技術と特化型AI蒸留技術の独自アーキテクチャ |
| **Preferred Networks** | 未公表 | - |

> **注記:** 7件選定・5社契約という表記から、一部企業が複数モデルで応募・選定された可能性あり。

---

## 選定基準（重要）

源内に導入されるLLMに求められた要件は以下：

| 要件 | 内容 |
|---|---|
| **日本語適合性** | 日本語の語彙・表現・行政文書の記述様式に適合 |
| **セキュリティ** | ガバメントクラウド上の推論環境で動作（機密性2情報を扱える） |
| **ベンチマーク** | 海外主要LLMとの比較テスト結果を提供 |
| **安全性** | ハルシネーション・バイアス・有害コンテンツへの対策が明確 |
| **学習データ** | 法令遵守状況が説明可能 |
| **無償提供** | 2026年度中は無償（インフラ費用はデジタル庁負担） |

**最重要ポイント:** APIではなく**ガバメントクラウド内にモデルをデプロイして推論**する方式が必須条件。クラウドAPIを外部から叩く形では機密性2情報を扱えないため。

## 自作AIアプリで使えるLLMの選択肢

源内プロトコル準拠の独自AIアプリを作る場合、LLMは自由に選べる。用途に応じた選択肢：

### 国産LLM（商用）

| モデル | 提供形態 | 向いている用途 |
|---|---|---|
| **tsuzumi 2（NTT）** | API / オンプレ | 日本語全般、オンプレ重視 |
| **PLaMo翻訳（Preferred Networks）** | API | 日英翻訳特化 |
| **Takane（富士通）** | 未公表 | エンタープライズ向け |

### 海外LLM（現在の源内のベース）

| モデル | 特徴 |
|---|---|
| **GPT-4o（OpenAI）** | 源内がOpenAIと連携協定 |
| **Gemini（Google）** | Lawsy（GCP版）で使用 |
| **Claude（Anthropic）** | 高い日本語対応 |

### ローカルLLM（Proxmox環境向け）

| モデル | 特徴 | 必要リソース |
|---|---|---|
| **Llama 3.1 8B** | Meta製、日本語対応そこそこ | GPU 8GB〜 |
| **Qwen2.5 7B** | 中国Alibaba製、日本語強い | GPU 8GB〜 |
| **gemma 3 9B（Google）** | 軽量・高性能 | GPU 8GB〜 |
| **tsuzumi（NTT、将来）** | オンプレ対応予定 | GPU 1枚で動作 |

## Proxmox環境での現実的なLLM運用

源内のAIアプリにローカルLLMを組み合わせる場合の推奨構成：

```
Proxmox LXC/VM
├── Ollama（LLMランタイム）
│   ├── llama3.1:8b
│   └── qwen2.5:7b
└── 自作AIアプリ（FastAPI）
    ├── POST /  ← 源内プロトコル準拠
    └── Ollamaを内部で呼び出す
```

```python
# Ollamaを使った最小実装例
import httpx
from fastapi import FastAPI

app = FastAPI()

@app.post("/")
async def query(req: dict):
    question = req["inputs"]["input_text"]
    
    # Ollamaを呼び出す
    response = httpx.post("http://localhost:11434/api/generate", json={
        "model": "llama3.1:8b",
        "prompt": question,
        "stream": False
    })
    
    return {"outputs": response.json()["response"]}
```

## 重要な気づき

**2027年度から有償調達になる。**

つまり現在（2026年度）は国産LLMを無償で試せる時期。ただしこれは政府調達の話であり、自分たちが使う場合は別途各社との契約が必要。

**ガバメントクラウド外では使えない制約がある。**

選定されたモデルはガバメントクラウド上での動作が条件なので、Proxmox等の自前環境に持ってくることは基本的にできない（tsuzumi 2はオンプレ対応している点が例外的に注目）。
